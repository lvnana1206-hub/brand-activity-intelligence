# 品牌活动情报系统

跟踪影石目标用户高度重合品牌的最新公开活动信息，重点覆盖中国市场并兼顾海外灵感。

## 功能

- **品牌活动看板** - 品牌活动总览与快速筛选
- **品牌活动总览** - 年度节奏学习时间线与高转化活动分析
- **线下活动专项** - 线下活动深度监控
- **品牌活动学习时间线** - 按月份展示特殊节日、主题打法、重点品牌和代表活动

## 品牌范围

- 中国消费电子核心品牌（华为、小米、荣耀、OPPO、vivo 等）
- 重点车企品牌（比亚迪、蔚来、小鹏、理想等）
- 年轻人品牌（喜茶、霸王茶姬、泡泡玛特等）
- 户外运动品牌（Salomon、HOKA、始祖鸟等）

## 技术栈

- Python（数据采集、页面生成）
- HTML/CSS/JS（看板展示）
- CSV（数据存储）
